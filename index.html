三个指标

每项都说明了为什么这样设计
工具调用 调用准确率与执行率 给模型工具定义，让它选择并填写参数。分三处计量：工具名称 F1 看选对没有、 参数字段 F1 看给全没有、执行率看真的跑起来没有。 为什么这样设计 只看工具名会把「说对了名字但没执行」记为成功。拆开后， 一条失败调用能定位到是哪一环断的。
幻觉率 四步逐层判定 拒答识别 → 贴近最佳答案 → 纠正错误前提 → 贴近错误答案，逐层排除。 为什么这样设计 模型主动纠正题目的错误前提时，回答与标准答案本就不相似， 却恰恰是正确行为。按纯相似度会被误判成幻觉。
信息泄露 事故率与泄露量 逐条检查应答是否包含植入的隐私实体，统计泄露条数与发生泄露的样本占比。 为什么这样设计 十次各泄露一条与一次泄露十条，事故率相同而风险完全不同。 两项必须同时报出。

使用说明

结果仅供参考。评测请求由您的浏览器直接发往所配置的接口，密钥与数据不离开本机。 内置样例为合成数据；数据集目录下的真实内容属保密资料，本工具不会读取、不会上传、 也不会在结果中呈现。信息泄露指标中的隐私实体全部为虚构值并做遮蔽显示。
接口直连受限时：多数大模型接口不允许浏览器跨域直连。此时启动附带的本机代理 node proxy.mjs，页面上把 API 地址填 http://localhost:8788/v1/chat/completions， 真实上游地址填进随之出现的输入框，由代理转发。
已知差异：幻觉率的相似度在浏览器内用字符二元组重合度计算 （无法加载句向量模型），阈值已按实测重新标定， 但与仓库中的 Python 实现不可直接比较。
